# Student Performance & At-Risk Prediction

An internship assessment prototype for **ALGIONS AI LABS PRIVATE LIMITED**. It demonstrates EDA, leakage-aware training/evaluation, and an advisory Streamlit inference dashboard using a saved scikit-learn pipeline. The 1,000-row dataset and labels are synthetic; this project is not evidence of real-world student risk prediction.

## Requirements and installation

The saved model records **Python 3.9.6** and its training dependency versions. Python 3.9.6 is the tested interpreter for this project, but Python 3.9 reached end of life on 2025-10-31; choose a maintained Python version and revalidate joblib model loading before using this artifact outside the assessment environment ([Python version status](https://devguide.python.org/versions/)). `constraints-py39.txt` pins the direct runtime and notebook dependencies that were verified; it is a compatible constraints file, not a full transitive lock. For a fresh environment:

```bash
python3.9 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt -c constraints-py39.txt
```

The notebook dependencies (`ipykernel`, `nbclient`, `nbconvert`, and `nbformat`) are included in `requirements.txt`. Commands below assume they are run from the project root with the environment activated.

## Run the dashboard

```bash
streamlit run app.py
```

The app loads `reports/model_artifacts/at_risk_pipeline.joblib` and saved evaluation JSON; it does not train a model or generate data at runtime. It validates the four input percentages, derives assessment trend using the same one-decimal calculation as the generator, and presents the saved model score, threshold, and advisory band. The score is not calibrated. Feature signals describe model associations, not causes. Predictions are advisory only and must not determine punishment, grades, or admissions; human review is required.

## Reproduce data, training, and analysis

The checked-in CSV is generated by `src/data/generate_data.py` with 1,000 records and seed 42. Each row represents a unique synthetic student. A simulated next-assessment score determines `at_risk` (1 when the score is below 40), but that future score is not stored or used as an input. `student_id` and `at_risk` are excluded from the explicit five-feature training allowlist.

These commands reproduce the dataset and training outputs under `/tmp` so the checked-in dataset, saved model, threshold, evaluation results, and figures are left untouched:

```bash
python -m src.data.generate_data --records 1000 --seed 42 --output /tmp/student_performance.csv
python -m src.models.train --data /tmp/student_performance.csv --report-dir /tmp/student-performance-reports --seed 42
```

Training uses fixed-seed stratified 70/15/15 splits because the generator creates independent rows with no repeated student observations. Preprocessing is fitted in scikit-learn pipelines on training rows only. Validation F2 selects the candidate and tunes decision thresholds; the test split is held out for reporting. Reproduction requires the recorded Python/dependency versions for comparable fitted artifacts.

To execute EDA and refresh its saved figures (this writes to `reports/figures/`):

```bash
python -m jupyter nbconvert --to notebook --execute notebooks/eda.ipynb --output eda_executed.ipynb --output-dir /tmp
```

## Data, privacy, and limitations

The generator uses a known formula with random noise and produces no real student records or sensitive attributes. The checked-in `data/processed/student_performance.csv` is intended to be the reviewed synthetic demonstration dataset. Raw and locally collected data are ignored by Git. Before publication, inspect every data file; never add real, identifiable, confidential, or otherwise unauthorized student records. `.gitignore` cannot replace a content review.

The positive class is only 9.1% overall and the held-out test set has 14 positive records. Metrics therefore have substantial sampling uncertainty. There is no calibration study, subgroup fairness evaluation, external validation, or intervention-impact study. False negatives can miss a possible support need; false positives consume human review capacity and can create unnecessary concern. This model must not make consequential educational decisions.
